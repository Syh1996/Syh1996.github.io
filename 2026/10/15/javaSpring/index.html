    1.3 HttpServletRequest / HttpServletResponse（前置了解）

    一句话：SpringMVC 里所有参数注解（@PathVariable、@RequestParam、@RequestBody…）都是 Tomcat 把 HTTP 报文解析成 HttpServletRequest 之后，从里面取值再填到你的方法参数上。看懂原生对象，后面 9 种参数接收方式就不用死记硬背。

    1.3.1 一次 HTTP 请求的完整链路

    核心结论：Controller 方法的每个参数，都是由 HandlerMethodArgumentResolver（参数解析器）从 HttpServletRequest 里解析出来并做类型转换的。注解的作用只是告诉它——去哪儿取、怎么转、要不要必填。

    1.3.2 HttpServletRequest 常用 API

    方法 作用 示例返回值
    getMethod() 请求方式 GET / POST
    getRequestURI() 请求路径（不含域名） /api/users/1
    getRequestURL() 完整 URL http://localhost:8080/api/users/1
    getQueryString() URL 上的查询串 page=1&size=10
    getParameter(name) 取请求参数（URL 或表单） 1
    getParameterValues(name) 取同名多值参数 ["1","2","3"]
    getParameterMap() 所有参数 {page=["1"], size=["10"]}
    getHeader(name) 取请求头 Bearer xxx
    getHeaderNames() 所有请求头名 枚举
    getCookies() 取所有 Cookie Cookie[]
    getInputStream() / getReader() 读请求体（JSON 原始报文） 只能读一次
    getContentType() 请求体类型 application/json
    getRemoteAddr() 客户端 IP 127.0.0.1
    getSession() 获取 Session HttpSession
    getAttribute(name) 取请求域属性（配合拦截器传值） setAttribute 存进去的东西
    getServletContext() 应用上下文 ServletContext

    1.3.3 HttpServletResponse 常用 API

    方法 作用
    setStatus(int) 设置状态码（如 401/404）
    setContentType(String) 设置响应类型
    setCharacterEncoding(String) 设置编码
    setHeader(name, value) 设置响应头
    addHeader(name, value) 追加响应头（可重复）
    getWriter() 字符输出流（写文本/JSON）
    getOutputStream() 字节输出流（写文件/图片）
    sendRedirect(url) 重定向
    addCookie(Cookie) 写 Cookie 给浏览器
    sendError(404) 直接返回错误页

    Spring 注解 等价于原生写法
    @RequestParam("id") Long id request.getParameter("id") + 类型转换
    @PathVariable("id") Long id 从 request.getRequestURI() 里截取路径段
    @RequestBody UserDTO dto request.getReader() 读流 + Jackson 反序列化
    @RequestHeader("Authorization") request.getHeader("Authorization")
    @CookieValue("JSESSIONID") 遍历 request.getCookies() 找同名 Cookie
    UserQueryDTO query（无注解） 遍历 request.getParameterMap() 按属性名反射赋值
    @RequestParam List<Long> ids request.getParameterValues("ids") + 逐个转换
    @RequestParam MultipartFile file request.getParts() 取上传的二进制部分
    @ResponseBody response.getWriter().write(JSON.toJSONString(obj))
    @Valid 手动 if (dto.getUsername() == null) { ... }

    1.3.6 什么时候必须用原生对象

    日常 CRUD 优先用注解，原生对象只在以下场景兜底：

    1. 文件下载 / 验证码 / 图片：需要直接操作 response.getOutputStream()
    2. 写 Cookie：response.addCookie(new Cookie("token", token))
    3. 拦截器与 Controller 传值：request.setAttribute("userId", 1L) → Controller 里 request.getAttribute("userId")
    4. 获取真实 IP：经过 Nginx 代理时要读 X-Forwarded-For 头
    5. 接口验签：需要读取原始请求体做签名比对（此时不能用 @RequestBody，否则流已被消费）
    6. 导出 Excel / CSV：直接写输出流，避免大文件撑爆内存

    1.11 常见坑与排查

    现象 原因 解决
    接口 404 ① 启动类包路径太深 ② 路径拼写错 ③ 没加 @RestController 启动类放最外层包；检查 @RequestMapping 拼接结果
    @RequestBody 报 415 前端没带 Content-Type: application/json axios 设置 headers: {'Content-Type':'application/json'}
    日期参数 400 字符串无法转 LocalDate 加 @DateTimeFormat 或全局 spring.mvc.format
    Long 传到前端精度丢失 JS 数字最大安全值 2^53-1，id 太长 全局把 Long 序列化为 String，或字段改 String
    中文乱码 响应未指定 UTF-8 produces = "application/json;charset=UTF-8"
    参数接收到 null ① 名字不一致 ② 用了 @RequestBody 但传的是表单 核对参数名；表单提交去掉 @RequestBody
    OPTIONS 预检失败 跨域未放行 OPTIONS CORS 配置里加上 OPTIONS 方法
    @Valid 不生效 忘了加 @Valid / 嵌套对象没加 @Valid @RequestBody；嵌套字段加 @Valid
    拦截器不生效 没注册到 WebMvcConfigurer，或被 excludePathPatterns 排除了 检查注册代码和路径匹配规则
